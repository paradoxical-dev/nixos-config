# User Modules

Contains the modules for installing packages on the user level. Each option provided is described within the `README` of the containing modules directory.

Within this directory there is also a [default.nix](./default.nix) file. This file imports every module within this directory to define the available optoins within `userSettings`.

Also contained in this directory is the [home.nix](./home.nix) file. This file describes the base packages and default home-manager options for every install.
