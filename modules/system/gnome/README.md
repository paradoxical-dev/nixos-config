# GNOME

Installs the GNOME desktop environment. Also handles the installation of GNOME extensions, icon packs, and cursor packages. Refer to the respective [users module](../users/gnome/) for home-manager options.

## Packages

- Papirus Icon Pack
- Bibata Cursors
- gnome-tweaks

### Extensions

- user-themes
- open-bar
- vitals
- blur-my-shell
- just-perfection
- dash2dock-lite
- tiling-shell
- space-bar
- gnome-40-ui-improvements

## options

### `gnome.enable`

Enables the installation of the GNOME desktop environment and accompying packages

**Type**: `bool`
**Default**: `false`
