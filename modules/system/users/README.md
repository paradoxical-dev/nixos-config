# Users

This module creates an option to create user(s) and admin user(s) on the system. Each provided user will be mapped over and provided the home-manager options described in the [users](../users) directory.

## options

### `users`

A list of users to create.

**Type**: `list`

**Default**: `[]`

### `adminUsers`

A list of users to create as admin users

**Type**: `list`

**Default**: `[]`
