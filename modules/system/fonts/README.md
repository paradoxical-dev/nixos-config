# Fonts

Font packages for the system.

## Options

### `fonts.std`

A list of stanfard fonts to install.

**Type**: `list`
Default: `[ pkgs.noto-fonts ]`

### `fonts.nerd`

A list of nerd fonts to install. Packages listed here should be included in the `pkgs.nerd-fonts` namespace

**Type**: `list`
Default: `[]`
