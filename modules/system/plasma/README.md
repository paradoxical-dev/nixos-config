# Plasma

Installs the KDE Plasma desktop environment. Also handles the installation of Plasma extensions, icons and cursor packages. Refer to the respective [user module](../user/plasma/) for home-manager options.

![Plasma home](https://i.imgur.com/i7dJZjU.png)
![Plasma apps](https://i.imgur.com/0MSs1pV.png)

## Packages

- plasma6

### Extensions

- Panel colorizer
- Panel spacer extended

## Options

### `plasma.enable`

Enables the installation of the Plasma desktop environment and accompying packages

**Type**: `bool`

**Default**: `false`
